# Model Flags

HydroPol2D is controlled by binary and categorical switches. In the case workbook `HydroPol2D_Inputs.xlsx`, each switch sits at the top of the block it controls, on the tab of its process, and the block greys out while the switch is 0. There is no separate `Flags` sheet. The [Case Workbook Settings](./general_data) page lists every block with its settings.

This page lists every switch by tab, then the rules for combining them.

## Rules for combining switches {#rules-for-combining-switches}

- Only one major routing family should be active at a time: `flag_full_momentum`, `flag_inertial`, `flag_diffusive`, `flag_kinematic`, or `flag_CA`.
- Select at most one subgrid formulation: Neal channel, structured lookup, or Voronoi lookup.
- `flag_voronoi = 1` selects the mesh topology; `flag_voronoi_subgrid = 1` additionally enables Voronoi lookup hydraulics.
- `flag_D8` is retired; keep it at 0. D8 local-inertial routing (`flag_d8_local_inertial`), urban drainage, detention ponds and green infrastructure are set in the bypass script, not in the workbook (see [Limitations](../validation/limitations#matlab-optional-modules)).
- `flag_numerical_scheme` (`1` Bates, `2` upwind, `3` centered) applies to the local-inertial family only.
- Snow needs the internal meteorological forcing: `flag_ETP = 1` and `flag_input_ETP_map = 0`. Snow parameters are columns of the land-use class table.
- `flag_implicit_water_table_flux` and the other layered-subsurface settings are read only with `flag_layered_subsurface = 1`.
- Human-instability mode `2` is not implemented. Use `1` or `3`.

### Neal (2012) channel subgrid {#neal-2012-subgrid-model-configuration}

The supported channel-subgrid mode follows [Neal et al. (2012)](https://doi.org/10.1029/2012WR012514). Use this combination:

| Switch | Required value |
|---|---:|
| `flag_inertial` | `1` |
| `flag_neal_channel` | `1` |
| `flag_structured_lookup_subgrid` | `0` |
| `flag_voronoi_subgrid` | `0` |
| `flag_voronoi` | `0` |
| `flag_full_momentum` | `0` |
| `flag_diffusive` | `0` |
| `flag_kinematic` | `0` |
| `flag_CA` | `0` |
| `flag_river_rasters` | `1` when channel geometry is supplied as rasters |

The active channel cells require both `RiverWidths_path` and `RiverDepths_path`. Channel width and depth must be positive, and channel width must be smaller than the model-cell resolution. The channel Manning coefficient is the `Manning` setting on the Surface flow tab. The land-use roughness supplies the floodplain Manning coefficient.

The solver computes channel and floodplain discharge separately on each orthogonal face and updates cell storage in volume space. The formulation and validation range are described in [Hydrodynamic Model](../theory/hydrodynamic-model#115-neal-2012-subgrid-model) and [Neal (2012) Subgrid Model Validation](../validation/neal-subgrid).

## Older layout {#older-layout}

In cases that use `General_Data.xlsx`, the switches are rows of its `Flags` sheet, with the value in column E. In the distributed workbooks `flag_deep_aquifer`, `flag_layered_subsurface`, `flag_feddes` and `flag_implicit_water_table_flux` are rows 37 to 40. The model reads the `Flags` sheet when the case has one, and the switches of the settings tabs otherwise.

- The retired switches `flag_data_source`, `flag_dam_break` and `flag_river_heigth_compensation` are no longer required (default 0).
- `flag_subgrid` and `flag_overbanks` are derived from the channel switches. Older inputs that still set them are accepted by the migration layer, with a warning.
